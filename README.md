# Varal

Varal ("clothesline" in Portuguese) is a native macOS desktop utility that hangs daily task slips and live companion cards on a physics-driven clothesline at wallpaper level. Tasks are completed by tearing slips off the line into a laundry basket — no notifications, checkboxes, or streaks.
